# Imagens da Landing Page - Aula Secreta

Coloque aqui os arquivos de imagem para personalizar a sua Landing Page:

1. **Foto de Mathyas Santos**:
   - Nome sugerido: `mathyas-santos.jpg` (ou `.png` / `.webp`)
   - Caminho no código: `assets/images/mathyas-santos.jpg`
   - Formato recomendado: Retrato vertical (3:4 ou 1:1), alta resolução (ex: 800x1000px).
   
2. **Thumbnail do Player de Vídeo (Opcional)**:
   - Nome sugerido: `video-thumb.jpg` (ou `.png` / `.webp`)
   - Caminho no código: `assets/images/video-thumb.jpg`
   - Formato recomendado: Proporção 16:9 (ex: 1280x720px ou 1920x1080px).
   - Se preferir usar um vídeo real em vez de simulação, basta descomentar a tag `<video>` ou o `<iframe>` no `index.html`.

Enquanto nenhuma imagem for adicionada, a página utiliza uma moldura estilizada em SVG e gradiente neon dark que preserva o layout perfeito.
